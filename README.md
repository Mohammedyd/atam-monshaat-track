# مسار الأعمال والحوكمة الرياضية: نسخة المعاينة الداخلية

نسخة للفريق الداخلي في أتام لتجربة المسار كاملاً: البرامج الأربعة والاختبار الختامي. تحاكي هذه النسخة تسجيل منصة التعلم داخل المتصفح. لا تُرفع إلى منصة منشآت، فالذي يُرسل هو حزم SCORM بصيغة ZIP.

## المحتوى

| المسار | الصفحة |
|---|---|
| `index.html` | صفحة المسار: البرامج، وحالة كل برنامج، وقائمة ما يُطلب تجربته |
| `p1/` | البرنامج 01: الاستثمار في قطاع الرياضة |
| `p2/` | البرنامج 02: العلامات التجارية والامتياز التجاري |
| `p3/` | البرنامج 03: الحوكمة في قطاع الرياضة |
| `p4/` | البرنامج 04: الرعايات في قطاع الرياضة |
| `exam/` | الاختبار الختامي للمسار |
| `assets/` | المشغل والخطوط والصور، وكلها محلية بلا روابط خارجية |

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً، ثم ارفع **محتويات** هذا المجلد إلى جذره. يجب أن يكون `index.html` في الجذر.
2. من إعدادات المستودع: Settings ثم Pages، ثم Source: Deploy from a branch، ثم اختر `main` والمجلد `/ (root)`.
3. بعد دقيقة أو دقيقتين يظهر الرابط بالشكل `https://<الحساب>.github.io/<اسم المستودع>/`.

## تنبيه السرية

- **في الخطة المجانية** لا تعمل GitHub Pages إلا مع المستودعات العامة. يعني هذا أن الملفات وصفحة الموقع تكون متاحة لأي شخص يعرف الرابط.
- **الصفحات الخاصة** المقصورة على أعضاء المؤسسة تتطلب اشتراك GitHub Enterprise Cloud.
- **منع محركات البحث:** أُضيف `robots.txt` ووسم `noindex` لمنع الفهرسة، لكن هذا لا يمنع الوصول عبر الرابط.
- **القرار قبل النشر العام:** المحتوى لم يُرسل إلى منشآت بعد. قرر قبل النشر العام هل يناسب أن يكون متاحاً بالرابط.

## التجربة محلياً دون نشر

افتح `index.html` مباشرة من المجلد، ويعمل في كروم وإيدج دون إنترنت.
